# Ecosistema Mudanzas — Arquitectura estratégica

## Rol del proyecto

**Mudanzas en Mendoza = QUÉ SABER**

Este dominio funciona como capa de autoridad temática e información útil. Su objetivo es responder preguntas del usuario antes de la contratación y derivar, cuando corresponde, hacia MudanzaPro para resolver la tarea.

## Principios

1. No competir con MudanzaPro como herramienta.
2. No competir con Mudanzas Miranda como proveedor.
3. Priorizar contenido útil, verificable, local y directamente accionable.
4. Cada página debe responder una intención principal.
5. Las páginas comerciales o de proveedor deben enlazar hacia el producto adecuado sin crear canibalización.

## Arquitectura de información objetivo

- Inicio
- Guía para mudarse en Mendoza
- Costos de mudanza
- Cómo preparar una mudanza
- Embalaje
- Tipos de mudanza
- Mudanzas por zona
- Checklist
- Preguntas frecuentes
- Herramientas → MudanzaPro

## Clusters SEO/GEO

- mudanzas en Mendoza
- costos y precios de mudanza
- preparación y organización
- embalaje
- tipos de mudanza
- búsquedas locales por departamento/ciudad
- preguntas frecuentes sobre mudanzas

## Transferencias del ecosistema

- Información → MudanzaPro cuando el usuario necesita calcular, organizar o resolver.
- MudanzaPro → Mudanzas Miranda cuando el usuario necesita contratar un proveedor.
- No usar enlaces cruzados indiscriminados: cada enlace debe tener una intención clara.

## UX/UI

El lenguaje visual debe favorecer lectura, jerarquía editorial, escaneabilidad, confianza y acciones contextuales. Los componentes pueden compartir Design System con los otros proyectos, pero la expresión visual debe seguir el rol editorial.

## SEO/GEO

Cada página debe definir título, descripción, canonical, breadcrumbs y entidad/schema apropiado. Las respuestas deben estar redactadas para ser comprensibles tanto por usuarios como por sistemas de recuperación y respuesta de IA.

## QA

Antes de cualquier cambio visual: baseline en 375×812, 768×1024 y 1440×900. No introducir rediseños globales sin evidencia de QA.
